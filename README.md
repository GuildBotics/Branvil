# Branvil

Branvil has moved into the GuildBotics repository:
[GuildBotics/GuildBotics](https://github.com/GuildBotics/GuildBotics).

Branvil is the `branvil` crate in
[`crates/branvil`](https://github.com/GuildBotics/GuildBotics/tree/main/crates/branvil).
GuildBotics runs it in the same process as the GuildBotics server, and its
commands are `guildbotics branvil ...`. Start from the crate's
[README](https://github.com/GuildBotics/GuildBotics/blob/main/crates/branvil/README.md).

This repository is archived and receives no further changes. Its history up to
the move stays here. Send issues and changes to
[GuildBotics/GuildBotics](https://github.com/GuildBotics/GuildBotics).
